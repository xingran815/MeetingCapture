## Surprises
- **Codex search:** with all features off it fails with "code-mode host is disabled", and the model then answers from memory with 0 tool events. Search calls keep only `code_mode_host` on, with the shell off. Trimmed plain calls use 2,884 input tokens against 30,185 untrimmed.
- **GitHub Push Protection** rejected invented Slack, AWS ID and URL-key shapes in fixtures. It scans all pushes, separately from the ruleset. The unblock link was not used; the values were replaced and the unpushed commits rebuilt.
- **`scripts/test-sweeps.sh` damages git config** when pushed from a linked worktree, because it doesn't clear `GIT_DIR`. Reported and repaired by a peer session. M2.1 fixes the script.
- **Zsh doesn't split words**, so probe scripts failed with 127. Run them with bash.

## Still unsure
- **Softened fixture values:** the Slack, AWS and URL-key fixture values were changed after the quality runs, because of Push Protection. The redaction score was re-run after the change; the quality tables were not. The softened values are easier to spot as fake and may be slightly easier to match.
- **Claude `ind-07`** was rated 2/3 with regex against 4/4 without. Rater notes aren't saved. One repeat read by hand was accurate, but the reason is not explained.
- **Quality compares counts per transcript,** not per fact, so a lost fact offset by a gained one wouldn't show.
- **`CLIRequest.validate` is a heuristic backstop:** at most 6 words, no digits or certain punctuation. Two plain words of private text would pass it. Today only fixed concept names reach it, in `Diagnostics.swift` and a test. M4's frontier review must keep that true.
- **Codex limits** come from error text only (D-26). The real limit message hasn't been seen.
- **`NetworkRefusal`** covers `URLSession.shared` only.
