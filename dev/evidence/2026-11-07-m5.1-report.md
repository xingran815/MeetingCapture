**Status: done. Verifier passed; deep review approved after one fix round; security review found no high or medium issues. No 👤 check in this milestone.**

All data here is invented: the screenshots use a demo library (a garden fair and a book club) in a temp home (`MEETINGCAPTURE_HOME`), never the real output folder.

## What landed
| Area | Now |
|---|---|
| User's layer | `<base>.edits.json` (`userTitle`, content edits, `sendNotesToLLM`) and `<base>.notes.md`, merged whenever a report is shown or written (`Notebook.page`). `report.json` keeps only the model's output, so a re-run never overwrites them |
| Edits | Each keeps the model text it replaced; non-text fields also keep the item's text. Applied at their place, else at the one item in the section that still matches, else stale: reported ("N edits no longer match"), never applied. Keep puts a stale edit back over the text now at its place; Drop removes it (D-95) |
| Sidecar | New `reportFiles` (every dated page, in order) and `olderPagesUnrecorded`. A loose report gets a minimal sidecar. After a change, the newest page is written again in place |
| Delete | Moves to the Trash only: the sidecar's `audioFiles` and `reportFiles`, the fixed names (`.txt`, `.md`, `.report.md`, `.report.json`, `.edits.json`, `.notes.md`), then the sidecar last. Each name must be a plain entry in the folder, a regular file, and not listed by another sidecar. It refuses an unfinished recording, a busy one, and an unreadable sidecar; it moves only files the user confirmed; a pre-M5.1 page is left with a message |
| Notes to the LLM | Off by default, per report. When on, notes are redacted with the transcript in one token space and go to the sections step only, under a heading that says they're the user's |
| Terminal | Library › r rename, n notes (`$EDITOR` without a shell, else `open -t`), l send notes to the LLM, d delete (lists the files, asks). `w` asks whether to keep edits when the report has some |
| App | More › Rename…, Edit Report…, Move to Trash… (also in the Recording menu, ⌥⌘N notes, ⌘⌫ delete); a notes pane beside the report, saved as you type; a stale-edits banner with Keep and Drop; the keep-edits question on Write the Report Again |
| Parity | `docs/parity.md` rows for rename, notes, the notes switch, re-run with edits, delete; editing listed as desktop only |

## Surprises
- **A hand-written sidecar without `speakerNames` reads as unreadable**, because that field has no decode default. Delete then refused, which is the safe answer; real sidecars always have it.
- **Delete in the app uses the real Trash.** The demo's 7 invented files went to this Mac's Trash.

## Still unsure
- The notes pane and editing were checked by hand on one Mac; editing long text in the sheet's fields is plain, not rich.
- Only the newest page is re-rendered after a change; older dated pages keep what they showed (D-95).
