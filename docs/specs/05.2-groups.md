# M5.2: groups that share context

**Goal:** the user puts related reports in a group, such as a weekly team meeting or a series of sessions, and a new report in that group is written with the earlier ones as context. Starts after M5.1. Decisions: D-94.

## Design
| Part | Design |
|---|---|
| Grouping | Only the user groups reports: create, rename, delete a group; add or remove a report. Nothing is grouped automatically. Stored in `groups.json` in the output folder, by **base name** (not path), so a moved folder still works. M5.1's delete removes the base from its group |
| What is sent | Built from an **allow-list** of report fields: title (`userTitle` if set), scenario, section titles, item `text` and `detail`, `priority`, `keywords`, and the user's edits. Left out: `transcript`, item `quote`, `reviewChanges`, notices. **Never a transcript.** Notes only where that report's notes switch is on |
| Privacy | Context redaction = global redaction **and** the group's switch: on by default, and the user can turn it off per group. A group can't turn it on when global redaction is off |
| One token space | The transcript and the context are redacted together as one text, so a name gets one token everywhere and restores correctly |
| How much | The newest reports in the group by the recording's `createdAt` (from the sidecar, which a re-run doesn't change), up to a cap in characters. The report's notices list which reports were used and which were left out |
| Quality | The review step checks each item against this transcript, and an item marked `source: earlier` against the group's earlier reports. A fact only an earlier report has is kept only when traceable and not contradicted, and the page marks it "From an earlier report" (D-97, which replaces "this transcript only") |
| Scenario (optional) | A group may pin its scenario (a therapy series stays therapy), skipping the classifier |
| Terminal | Groups are made and changed in both; the terminal can pick a group when writing a report |

## Done when
- [ ] A report written in a group names the reports it used and left out.
- [ ] A test plants a marker string in each excluded field (`transcript`, `quote`, `reviewChanges`, notes with the switch off) and proves none reaches the prompt.
- [ ] With redaction on, a name in both the transcript and a past report gets one token and is restored; with the group's switch off, the context goes as written; with global redaction off, nothing is redacted.
- [ ] 👤 The user compares a report written with group context against one without, on invented sessions.
- [ ] Parity checklist and verifier pass.
